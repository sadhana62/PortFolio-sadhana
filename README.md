

Personal portfolio site. Plain HTML/CSS/JS, no build step.

## Features
- Live GitHub repos (paginated, searchable, sortable)
- Live GitHub stats + language breakdown
- LeetCode stats
- About, Skills, Experience, Projects, Achievements, Contact

## Run locally
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000/portfolio.html`

## Tech
HTML, CSS, JavaScript — GitHub REST API, LeetCode stats API
